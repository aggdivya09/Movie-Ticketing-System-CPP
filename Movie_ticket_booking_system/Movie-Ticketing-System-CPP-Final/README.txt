# 🎬 Movie Ticketing System – C++

Menu-driven Movie Ticketing System developed in C++ for System Design.

## Build
Compile the complete submission using:

g++ -std=c++17 main.cpp -o movie_booking

Run:
./movie_booking

## Features
- Movie listing
- Show listing
- Seat layout with AVAILABLE/BOOKED status
- Seat booking
- Silver ₹150, Gold ₹250, Platinum ₹400
- UPI, Card and Cash payment options
- Ticket generation
- Booking cancellation
- Invalid and already-booked seat validation

## Seat Input
Both formats are accepted:
- 1, 2, 3, 4
- A1, A2, A3, A4

For example, entering 2 selects A2.
